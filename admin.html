SECURITY CHECKLIST

Before making the admin public

  • Protect the admin route with Cloudflare Access (owner-only identity policy).
  • Use a secure server-side publishing endpoint; never place API tokens or passwords in browser JavaScript.
  • Configure upload restrictions, file size limits and malware scanning strategy.
  • Enable backups and test restore before accepting real content.
  • Review disease and medicine content before publication; display sources and review dates.
